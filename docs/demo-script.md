# RightNow India: Two-Minute Demo Script

## Recording setup

- Use only the built-in synthetic household profile.
- Start with household data cleared and the civic inbox empty.
- Keep the independent-prototype disclosure visible.
- Use a desktop viewport wide enough to show the conversation and inbox.
- Turn notifications off and hide developer secrets, terminal history, bookmarks, and personal browser data.
- Target 1 minute 52 seconds to leave editing and playback buffer.

## 0:00 to 0:08: The problem

**Screen:** RightNow India home, headline “Tell us what changed.”

**Voiceover:**

“Citizens should not need to know which department owns a life event. RightNow India starts with what changed, then coordinates the relevant public services.”

## 0:08 to 0:17: Safety and consent

**Action:** Choose the pregnancy prompt. Show the short AI-processing notice, synthetic-data warning, and private fallback option. Continue with the demo-safe option.

**Voiceover:**

“This is an independent prototype using synthetic data. It never asks for identity numbers, OTPs, payments, or real documents.”

## 0:17 to 0:34: One adaptive conversation

**Action:** Enter or select answers to the pregnancy questions. Open “What RightNow knows” briefly to show that the same household facts are reusable and editable.

**Voiceover:**

“A multilingual conversation recognizes the mission and asks only for missing, non-sensitive facts. Language understanding can use GPT-5.6 Luna, but deterministic code alone decides readiness.”

## 0:34 to 0:50: Several services, one review

**Action:** Reveal PMMVY, JSY, JSSK, and birth-registration preparation. Open the consolidated review. Point to plain-language reasons, requirements, and official-source links.

**Voiceover:**

“One life change can involve several services. RightNow prepares them together, explains every outcome, and waits for one consolidated approval.”

## 0:50 to 1:00: Mock submission and inbox

**Action:** Approve. Show clearly marked mock reference numbers and the civic inbox timeline.

**Voiceover:**

“Only after approval does the mock gateway create demonstration references. The civic inbox keeps applications, deadlines, renewals, and discovered opportunities in one place.”

## 1:00 to 1:11: Prove the reusable system

**Action:** Return to the mission prompts and quickly highlight college, work, job loss, business, and grievance. If time permits, edit one household fact and show the automatic connector rescan.

**Voiceover:**

“The same engine supports six complete life missions and nineteen mock connectors. Profile changes rescan every connector, but autopilot can prepare only. It can never submit.”

## 1:11 to 1:27: Show Codex architecture

**Action:** Open `/built-with-codex`. Scroll to the architecture diagram and connector contract.

**Voiceover:**

“Codex turned the citizen problem into a schema-driven connector architecture. It separated multilingual interpretation from factual rules, then built the local profile, mock gateway, review, and inbox.”

## 1:27 to 1:41: Show test-first evidence

**Action:** Show the sanitized prompt-to-result examples and the final test panel. Use only verified final results. If a result remains pending, do not show it as passed.

**Voiceover:**

“Codex also wrote tests for connector outcomes, malformed model output, timeouts, deterministic fallback, data deletion, and all six journeys before final verification.”

## 1:41 to 1:52: Human and AI responsibility

**Action:** Show the “Codex produced / Builder decided” split, then return to the product headline.

**Voiceover:**

“The builder chose the problem, missions, interaction, and tradeoffs. Codex built and reviewed the prototype. GPT-5.6 Luna powers optional runtime conversation. Government systems are never called.”

## Optional on-screen closing line

**RightNow India. One conversation. Every public service.**

**Independent prototype. Synthetic data. Mock submissions only.**

## Fast fallback if the AI call is unavailable during recording

1. Choose private demo mode.
2. Select the pregnancy mission prompt.
3. Continue through the deterministic question flow.
4. Say: “The fallback is intentional. The service planner remains useful even when AI is unavailable or declined.”
