# RightNow India: Two-Minute Demo Script

## Recording setup

- Use only synthetic information.
- Clear the household so the civic inbox is empty and AI consent is unset.
- Keep the independent-prototype disclosure visible.
- Use a viewport that shows the conversation and inbox together.
- Target 1 minute 50 seconds to leave playback buffer.

## 0:00 to 0:12: The problem and promise

**Screen:** Home page with “Whatever changed, start here.”

**Voiceover:**

“Life does not arrive as a department or a form. RightNow India lets a person describe whatever changed, then turns it into a reviewable action simulation.”

## 0:12 to 0:30: Prove the open-ended route

**Action:** Type “My passport expired and I need to travel.” Choose “Always use AI routing” in the initial consent dialog.

**Voiceover:**

“The examples are prompts, not product limits. With explicit consent, AI routes an open-ended safe description through OpenCode Go. The choice stays in this browser and can be changed. I have entered no name, address, identity number, personal record, OTP, or payment detail.”

## 0:30 to 0:48: Show a specific generated plan

**Action:** Show the generated title, summary, and specific preparation steps. Point to the generated-simulation disclaimer.

**Voiceover:**

“For an open-ended need, the model creates a bounded planning brief. It cannot claim eligibility, invent a completed application, or contact anyone. If AI is unavailable, RightNow still returns a safe fallback instead of a dead end.”

## 0:48 to 1:05: Human review and simulation boundary

**Action:** Open “Review your plan,” inspect the steps, then simulate the selected plan.

**Voiceover:**

“The citizen stays in control. RightNow shows exactly what will be recorded and stops before any real-world action. Approval creates only a mock reference in this browser.”

## 1:05 to 1:24: Show a verified accelerator

**Action:** Start a new request: “I lost my job.” Answer the non-sensitive guided questions and show the source-linked service plan.

**Voiceover:**

“When a request matches a verified accelerator, deterministic connectors add official sources and ask only for missing facts. AI handles language and routing; code remains the authority for connector outcomes.”

## 1:24 to 1:36: Prove breadth without a catalogue claim

**Action:** Return to the top and point to passport, certificate, parent-support, moving, work, and business examples.

**Voiceover:**

“These are examples, not eight fixed journeys. The conversational entry is open-ended, while deeper verified connectors can grow independently.”

## 1:36 to 1:52: Codex evidence and close

**Action:** Open `/built-with-codex`, briefly show the architecture and verified test panel, then return home.

**Voiceover:**

“Codex helped design the schema boundary, build the product and mock gateway, and test sensitive-input rejection, provider failure, local deletion, review, simulation, and mobile flows. RightNow is honest about the boundary: useful preparation, never a fake government integration.”

## Closing line

**RightNow India. Whatever changed, start here.**

**Independent prototype. Synthetic data. Simulations only.**
